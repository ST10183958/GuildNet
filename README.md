# Guildnet

## Where Gamers Unite

Guildnet is a native Android application designed to provide gamers with a unified platform for community interaction, real-time communication, discussion and gaming knowledge sharing.

The application combines concepts inspired by Discord, Reddit and Fandom into a gaming-focused platform.

## Project Purpose

Guildnet allows users to discover and join game-specific communities, communicate through real-time Squad chat, participate in Clan discussions, create community posts and access community-created gaming guides through LoreVault.
